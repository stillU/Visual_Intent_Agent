# MVP v0.6：RAG 对照验证与结果闭环

日期：2026-09-16。状态：计划，尚未实施。本次只交付复查与任务书，不授权真实图片调用、正式评测或 Git 提交推送。

## 目标

验证同一系统开启/关闭 RAG 时，用户已委托的视觉决策是否得到帮助，并量化约束遵守、失败和成本。沿用 v0.5 五条已批准的项目偏好规则、普通业务数据库和确定性编译，不扩建 RAG。

本版不是证明通用语义理解全面提升，不是官方 GenEval/CompBench 评分，也不是原 v0.3 的 Direct LLM 对照 Gate A。没有收益或证据不足均是有效结论，不能为完成版本强行得出“提升”。

## 范围与完成定义

只新增必要的 v0.6 评测协议、工程适配、记录/报告与测试。建议在 evaluation/v0_6/ 中实现独立 B/C 编排并复用既有只读指标、身份与图像评审组件；不改写 v0.3 冻结物、不把旧 A/B Runner 改名后当成 B/C。

保持业务数据库模式、Intent/PIN/确认、候选/条件合同、RAG 默认关闭、现有语料快照和历史重试语义不变。失败只能补小范围评测层问题；需改运行时或知识内容时另提修复、新版本及审核，停止受影响的正式批次。

没有 G1 授权或盲评未完成，只能报告“离线准备完成 / 等待运行或评审”。正式阶段完成后可报告收益支持、未见收益、退化或证据不足；不能把测试全绿等同于质量通过。
