## 实施边界

- 不重写领域模型、Repository、生成链路，不新增 Web、RAG、多 Agent 产品框架或依赖。
- PIN、来源校验、确认绑定、Revision 与 Artifact 安全不变量不放宽。
- 001 中成立的语义纠错与评测修订仍是内容依据；不能为适配模型输出而篡改答案。
- 不读取或输出密钥，不修改 `.env`，默认测试完全离线；不启动真实付费批次。
- 子代理只做所需局部测试；协调者集中全量验收一次，失败时修具体根因，不循环重跑系统寻找成功记录。
- 尚未完成的细项明确列出，不以“已经派发”当作完成。
