日期：2026-09-16。状态：**已实施（v0.5 整体为部分完成）**——Step 00 完成；Step 01 部分完成（COCO-CN 许可暂不确认）；Step 02 / 03 / 04 完成。实施状态以 [docs/mvp_v0.5/README.md](../../mvp_v0.5/README.md) 与实际交接为准。

## 目标

将 v0.4 已接通的 RAG 工程链路变成能够使用真实审核知识的功能：在合适的已确认上下文中，为用户委托的视觉字段选择已有候选，保留正常数据库功能、用户控制和确定性编译。

v0.5 回答“知识是否可信、能否依法使用、能否被正确采用和追溯”；v0.6 再经用户授权回答“生成效果是否改善”。不以词法命中、测试通过或一张示例图宣称质量提升。

## 完成标准与暂停条件

- 三条路径各有至少一条真实审核通过、条件可达且许可明确的规则，并在 Fake Provider + 临时真实数据库中完成实际采用验证；不要求九条全保留，不追求更多条数。
- 任何路径缺乏可证明合理的规则，应保持回退并报告“部分内容完成”，不得为凑覆盖批准弱规则。三路径目标若不能满足，提交证据请用户裁定范围，不能自行宣布完整发布。
- 无真实审核决定时，最多报告“准备/工程部分完成，内容审核待定”；不能称 v0.5 全部完成。
- 有真实知识的集成测试不能只使用内置 demo approved 夹具；发布前必须验证最终语料快照。
- 旧数据库、历史 Artifact、原 Prompt retry 和关闭 RAG 的行为保持兼容；正式评测未执行。

## 范围与安全底线

只允许必要的资源准备工具、知识提案/发布资料、离线测试及小范围集成缺口修复。Intent/Policy/PIN/确认机制、三条知识路径、候选白名单和条件算子不扩展。保留当前 CLI 开关默认行为；使用已有 `--knowledge-dir` 选择新语料，不为本版改默认路径或新增产品界面。

不增加 Embedding、向量库、在线爬虫、任意用户文档接入、额外 LLM、图像编辑或多模型；不下载评测模型，不调用真实 Provider，不启动正式图像评分、A/B 或 Gate 判定。不改 `.env`、不删除用户数据库、不重写旧语料/历史记录，未经要求不提交推送。

每步写 `docs/handoffs/v0_5_step_XX_handoff.md`，最终写 `docs/handoffs/v0_5_release_handoff.md`。报告须分开列出工程、内容审核、数据准备、历史兼容与正式评测状态。
