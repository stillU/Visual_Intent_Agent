# RAG 知识与开放测试数据资源包

核查日期：2026-09-16。性质：供后续 Agent 使用的资源交接，不是新版本实施计划，也不是评测或生产知识批准记录。

## 入口与执行顺序

1. [测试数据](DATASETS.md)：GenEval、T2I-CompBench、COCO-CN，先准备文本，不下载图片或评测模型。
2. [知识来源](KNOWLEDGE_SOURCES.md)：光照、构图、景深资料及可用边界。
3. [固定资源清单](sources.lock.json)：下载地址、提交版本、已实测文件哈希和未完成核查项。
4. [Agent 操作指引](AGENT_DISPATCH_PROMPTS.md)：分阶段输入、产物、验收与停止条件。

最短路径：固定版本文本下载 → 独立暂存与许可归档 → 少量样本标注；同时整理知识证据 → 真实人工审核 → 另行授权后才开展正式评测。没有审核通过的知识时，只能验证空知识回退，不能宣称 RAG 效果提升。

所有后续操作均需当轮任务授权。本包不授权付费调用、正式图像评测、变更领域 Schema、安装大型评测依赖或提交推送。
