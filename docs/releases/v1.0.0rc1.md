## 5. 升级前注意事项（本记录不替你执行备份或迁移）

如需用本候选版本继续操作既有数据，请先自行完成：

1. **停止所有写库进程**：退出所有 CLI 会话，并确认没有评测 / 工具脚本仍在写同一个 SQLite 文件。
2. **备份完整数据库**：默认 `data/visual_intent.db`，或 `VIA_DB_PATH` 指向的文件；备份整个文件。
3. **一并保存适用的 SQLite 旁文件**：当前实现只设置 `PRAGMA foreign_keys`，**未显式启用 WAL**；若你的环境或工具启用了 WAL，请连同存在的 `*.db-wal`、`*.db-shm` 一起保存（不存在则无需）。
4. **备份输出并记录版本**：保存输出目录（默认 `outputs/generations/`，或 `VIA_OUTPUT_DIR`），并记录对应代码版本（当前提交 / 未提交状态）与语料版本（`knowledge_base/v0.5/manifest.json` 的 `v0.5-approved-1` 及其校验值；`knowledge_base/v0.4/` 草稿）。
5. **本记录不覆盖数据库、不替用户执行备份或迁移。** SQLite Schema 迁移由 `PRAGMA user_version` 在打开数据库时按需应用；因此升级前的备份是唯一的回退依据。
